Drop your sound files in this folder. Naming convention:

  damage-1.mp3, damage-2.mp3, ...    plays when a player loses life
  turn-1.mp3, turn-2.mp3, ...        plays when a turn ends
  timer-1.mp3, ...                   plays when the turn timer starts
  timerend-1.mp3, ...                plays when the timer hits zero

Rules:
- Formats: mp3, ogg, wav, or m4a
- One or more files per category; a random one is picked each time
- Keep files small (under ~200 KB) so they play instantly
- No spaces in filenames
- Upload them to GitHub in public/sounds/ and redeploy

Sound can be toggled per device:
- Phones: gear button -> Sound effects On/Off
- TV: press OK on the remote (first press enables, later presses toggle)
